=====================================================================
 SISTEMA AT v1.0 · IPD - DINADAF — ¿CÓMO LO EJECUTO?
=====================================================================

Este KIT es el paquete CONSTRUCTOR: contiene el código fuente, las
plantillas oficiales y TODAS las dependencias offline (carpeta
wheels\). El .exe debe generarse UNA vez en un equipo con Windows
(existen 2 caminos; elija uno):

---------------------------------------------------------------------
CAMINO 1 · PROBAR EL SISTEMA YA (doble clic, ~10 minutos)
---------------------------------------------------------------------
1. Instale Python 3.12 o 3.13:  https://www.python.org/downloads/
   → Marque la casilla "Add python.exe to PATH". NO use Python 3.14.
2. Descomprima este KIT en una carpeta propia del usuario
   (Escritorio o C:\SistemaAT). NUNCA en C:\Program Files.
3. HAGA DOBLE CLIC en:  EJECUTAR_SISTEMA.bat
   (la primera vez crea .venv e instala dependencias desde wheels\
   automáticamente; las siguientes veces abre directo).

---------------------------------------------------------------------
CAMINO 2 · GENERAR EL PORTABLE REAL (SistemaAT.exe, ideal p/ USB)
---------------------------------------------------------------------
1. Requisito: mismo Python 3.12/3.13 del Camino 1.
2. HAGA DOBLE CLIC en:  COMPILAR_EXE.bat  (tarda 3-8 min)
3. Resultado:
      dist\SistemaAT\SistemaAT.exe        ← el programa portable
      dist\SistemaAT_Portable_v1.0.zip    ← para copiar a la USB
4. Copie la carpeta dist\SistemaAT completa donde quiera (USB incluida)
   y ejecute SistemaAT.exe. En los demás PC NO hace falta Python,
   ni permisos de administrador, ni instalar nada.
   Datos: carpeta Data\ junto al exe (respalde copiándola).

---------------------------------------------------------------------
AVISOS ÚTILES
---------------------------------------------------------------------
· Windows SmartScreen (primera vez con el .exe): pulse
  "Más información" → "Ejecutar de todas formas".
· PDF (opcional): instale LibreOffice; si hay Microsoft Excel se
  usa automáticamente. Sin ambos, igual se generan los Excel.
· Plantillas: los 4 archivos de templates\ llevan nombres exactos.
  No los renombre.
· Guías completas: INSTALL.md (uso) e INSTALL_BUILD.md (compilación).
